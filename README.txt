CUSTOMIZING YOUR PROFILE PHOTO:
The homepage currently features an initials avatar placeholder (SS). To use your photo:
1. Save your photograph in this folder as profile.jpg
2. Open index.html and find:
   <div class="photo-placeholder" id="photo-placeholder">SS</div>
   Replace it with:
   <img src="profile.jpg" alt="Snehamol Shiju">
3. The modern glassmorphism frame and ambient gradient glow are already pre-styled.
